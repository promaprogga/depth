How to Run the Simple Video Depth Estimation App
================================================

This guide explains how to start the simplified Depth Anything 3 (DA3) Gradio web application for video depth estimation.

1. Activate your Virtual Environment
-----------------------------------
First, ensure that your Python virtual environment where DA3 dependencies are installed is active.
Open your terminal (PowerShell or Command Prompt) and run:

    .\venv\Scripts\activate

2. Run the Application
----------------------
Execute the following python script from the root of your `depth_analysis` project folder:

    python app_simple_video_depth.py

3. Access the Web Interface
---------------------------
Once the script is running, it will host a local server. You will see an output similar to:
    "Running on local URL:  http://127.0.0.1:7861"

Open your web browser and go to:
    http://127.0.0.1:7861

4. How to Use
-------------
- Click on the "Input Video" box to upload your target `.mp4` video.
- Click the "Process Video" button.
- Wait for the model to process each frame (you can check terminal output to see the progress).
- Once finished, the "Depth Video" section on the right will display the generated depth map video.

Notes:
- The app uses `depth-anything/DA3MONO-LARGE`, which downloads automatically the first time if not already cached.
- Processing times will depend on the video length, resolution, and your GPU capabilities.
